# CI shards (D-2984), 19 October 2026

Dev-1. Branch `ci-e2e-shards` from `next` cfa8ba6. Why: #123's green run sat at 18 of the checks job's 20 minutes and 38 of the Supabase job's 40, and #125's runs were cut by the job timeout, not by a test (PO, 19 Oct 05:50).

## What changed

- The checks job keeps lint, format, typecheck, unit, the exam and docx-lint reports, the build, the client-bundle check, the security-headers check and the lawyer's bundle. It no longer installs browsers or runs Playwright. Timeout 20.
- A new `e2e` job runs the public end-to-end suite as a matrix of two shards (`--shard=1/2`, `--shard=2/2`), one worker each, retries as the Playwright config has them (untouched). Each shard checks out, installs, builds and installs its own browsers. The subscription-off run sits on shard 1 and the fixture business-identity run on shard 2. The Playwright report uploads on failure as `playwright-report-shard-N`. Timeout 20, `fail-fast: false` so one red shard does not hide the other.
- The Supabase job keeps the local stack, the migrations, the RLS and tenancy tests (once), the restore rehearsal with its second integration run, the build and the signed-in performance budget. It no longer runs the signed-in specs. Timeout 40.
- A new `signed-in-e2e` job runs `e2e/signed-in` as a matrix of two shards, one worker each, each shard starting its own local stack (a stack lives on one runner, so a shard cannot wait on another job's). The generation-off spec sits on shard 2. The screenshots upload as `signed-in-screenshots-shard-N` and the report on failure as `playwright-report-signed-in-shard-N`; each shard stops its stack. Timeout 40.
- Every other job is as it was. `scripts/ci/workflows.test.ts` pins the shape: two shard matrices, one worker through `--shard`, the artefact names with the shard, the two timeouts, the integration suite still run twice in the Supabase job and the signed-in specs no longer in it.

## Costs

Two more runners per run (the two shard jobs each start a stack and build once more). GitHub's free minutes for a public repository are not metered, so the cost is wall time on the runner pool, not money (`free-tier` skill, read 19 Oct 2026).
